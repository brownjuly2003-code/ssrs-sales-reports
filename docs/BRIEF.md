# Задача

## Что обещано

SSRS осваиваю в учебном проекте на SQL Server 2022 Developer: параметризованный отчёт по продажам и остаткам магазинов и рассылка его по подписке. Коммерческого опыта с SSRS нет. Шаги обещания:

1. Развернуть SQL Server 2022 Developer вместе с SSRS на Windows.
2. Собрать синтетическую базу магазинов: продажи, остатки, справочники.
3. Сделать отчёт в Report Builder с параметрами (период, магазин, категория) и группировками.
4. Настроить подписку с рассылкой отчёта по e-mail по расписанию.
5. Сравнить с тем же отчётом в Power BI.

Сценарий для отчёта: аналитику нужен утренний отчёт по магазинам. На печатной странице видны продажи за период и запасы на выбранную дату по регионам. В книге Excel руководитель может раскрыть свой регион до магазина и товара. Остатки ниже восьми единиц выделены цветом. [Январский отчёт в Excel](runs/2026-11-19-render/all.xlsx)

## Итог одной фразой

Синтетическая база магазинов загружается в SQL Server 2022 Developer, и шесть хранимых процедур отчёта исполняются на нём: списки трёх справочников совпадают с CSV, 148 итогов по строкам `ReportRows` и остаток `StockAtDate` для одной выборки совпадают с независимым расчётом по CSV, `SnapshotDates` возвращает даты снимков, а дата окончания без снимка остатков даёт пустой результат вместо нулевого запаса; параметризованный RDL с каскадом, группами до товара и подсветкой низкого остатка отрисовывается библиотекой ReportViewer в локальном режиме (данные передаёт приложение) в одностраничные PDF и книги Excel с теми же итогами — экспорт сделан до того, как дата окончания получила список дат снимков; запрос подписки и модель Power BI собраны как файлы, а четыре меры DAX модели вычислены движком модели данных Excel и в 600 строках контрольного запроса совпали с расчётом по CSV. Сервер SSRS не развёрнут, отчёт в Report Builder не открывался, рассылка по подписке не отправлялась, модель Power BI в Desktop не обновлялась, поэтому сравнение с Power BI в его интерфейсе не выполнено.
